# 1. view_alert_all [设备告警记录表]
> 记录设备的每一次告警信息，包含告警等级、告警时间、恢复时间、确认状态等

## 表结构

| 字段名 | 数据类型 | 主键 | 非空 | 默认值 | 备注说明 |
|--------|----------|------|------|--------|----------|
| 主机id | int4 | 否 | 是 |  | 设备主机的ID值 |
| 事件id | int4 | 否 | 是 |  | 告警事件id |
| 触发器id | int4 | 否 | 是 |  | 告警模版的ID值 |
| 设备名称 | VARCHAR(128) | 否 | 是 |  | 设备名称 |
| 告警信息 | VARCHAR(2048) | 否 | 是 |  | 告警信息的详细描述 |
| 告警等级 | VARCHAR(16) | 否 | 是 |  | 告警的严重等级 |
| 告警时间 | timestamp | 否 | 是 |  | 告警发生的时间 |
| 恢复时间 | timestamp | 否 | 否 |  | 告警恢复的时间 |
| 状态 | VARCHAR(16) | 否 | 是 |  | 告警是否恢复的状态 |
| 确认状态 | VARCHAR(16) | 否 | 是 |  | 告警确认的状态 |
| 确认人 | VARCHAR(16) | 否 | 是 |  | 确认告警人 |
| 关闭人 | VARCHAR(16) | 否 | 是 |  | 关闭告警人 |

<br>
